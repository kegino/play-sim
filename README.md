# Play Sim — Plataforma Oficial de Streaming IPTV

Website oficial do **Play Sim** (`playsim.website`), streaming IPTV de alta fidelidade com servidores CDN anti-travamento, mais de 35.000 canais ao vivo, filmes de sucesso, séries e transmissões esportivas em Full HD e 4K.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Performance**: Dados estruturados Schema.org (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS Feed nativo.
- **Identidade Visual**: Backdrop cinematográfico *Spider-Man: Across the Spider-Verse* otimizado em WebP leve (~110 KB), paleta Cyber Magenta & Electric Gold de alto contraste e legibilidade impecável para dispositivos móveis e desktop.

## 💻 Executando localmente

```sh
git clone https://github.com/kegino/play-sim.git
cd play-sim
pnpm install
pnpm dev
```

## 📦 Build para Produção

```sh
pnpm build
```
